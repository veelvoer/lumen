# Lumen 0.1.0

First release.

- Home screen with pages, dock and a pull-up app drawer (grid or list)
- Presets that restyle everything in one tap: Nothing, Pixel, iOS
- Customize: icon size and roundness, grid size, clock style (date, digital, dot matrix), search bar, dock style, accent color, dark or light
- Long-press an app to remove it, add it to the dock, hide it, open app info or uninstall
- Updates from GitHub inside Settings: tap Update and Android installs it
- Written in Rust; icons load in the background so scrolling stays smooth

Not tested on many phones yet. Please report what looks off.
