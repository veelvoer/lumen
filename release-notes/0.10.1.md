# Lumen 0.10.1

- Liquid Glass reworked: clearer glass with real edge lensing and bright rim highlights instead of a grey slab
- The keyboard no longer squishes the home screen; only search moves above it
- Icons that fail to load while you open/close apps quickly are retried, so none go missing
- Smoother icon jiggle (steady frame every vsync, folders jiggle too)
- Search is fully opaque over the home screen and its text is centered
- Edit buttons no longer sit on top of the status bar
