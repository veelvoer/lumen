# Lumen 0.10.11

- Icon wiggle is now a smooth dance: two blended sway speeds, a slow drift in strength, every icon at its own pace, and a ripple through the grid as each one starts
- Wiggling icons keep clean, smooth edges instead of crawling jaggies
- Open folders hide what is behind them, so home icons no longer show through the panel
- The dock now leaves before the App Library cards arrive, so the two never overlap
