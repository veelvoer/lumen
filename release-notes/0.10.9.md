# Lumen 0.10.9

- Opening and closing many apps in a row can no longer push Lumen into smooth mode or a lower refresh rate for good: slow frames during the system's own app animations are ignored, and nothing learned is kept between sessions
- If a frame ever fails, Lumen now rebuilds what it was drawing instead of showing an empty home screen
- Long-press menus are wider, so "Remove from Home Screen" no longer touches its icon
