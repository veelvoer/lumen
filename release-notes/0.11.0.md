# Lumen 0.11.0

- Coming back from an app no longer shows an empty, dark screen for a moment: Lumen now appears right as the app closes
  - Lumen paints your wallpaper itself (needs wallpaper access, Settings > Look; turn off with "Paint the wallpaper in Lumen")
  - The first start after granting access prepares it; it takes effect from the next start
- The wallpaper blur behind the drawer, folders and settings is done by Lumen too
