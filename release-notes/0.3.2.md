# Lumen 0.3.2

- Nothing preset: every app now gets a single-color glyph (its themed icon, the silhouette of its logo, or its strongest details), so the whole screen is black and white like the real thing.
- Search fields rise above the keyboard instead of hiding behind it.
- Idle battery use cut to a quarter: the background poller is slower and caches its Java lookups.
- Settings rows no longer run into their arrows.
