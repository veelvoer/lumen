# Lumen 0.5.0: built to run well on any phone

Reported janky on a Motorola G22, so this release is about speed everywhere.

- **Light mode (Auto).** Lumen checks the phone (memory, cores, graphics chip, Android version) and starts in a lighter mode on weak ones: no blur, no shadows, simple page slide, fewer animations and fewer background checks. If any phone keeps missing frames, Lumen switches itself to light mode and remembers. Settings > Performance lets you choose Auto, Full or Light and copy a report about your phone.
- **Far less drawing work.** App icons are packed into a few big textures and names are drawn in one batch, so a whole screen is a handful of draw calls instead of hundreds. Icons are cached on disk (the next start needs no Android calls), loaded at low priority, sized for your screen density, and prefetched gently when idle.
- **Smaller and lighter start:** fonts trimmed from 5 MB to 0.7 MB; big fonts for Chinese, Arabic, Thai and others load only when an app name needs them. Settings are shared, not copied, every frame.
- **Small screens fixed.** Icons shrink to fit when the grid is tight, so nothing overlaps on 320 dp phones.
- **Older Android (8 and up):** status bar, insets, haptics and refresh-rate calls now have fallbacks instead of failing.
- **Safer:** a bug in one frame skips that frame instead of crashing the launcher; apps with no icon get a letter.
- Settings pages that do not change the look (Performance, Behavior, Gestures...) no longer turn your preset into Custom.
